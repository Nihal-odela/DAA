#SUMMARY-SORTING ALGORITHMS
The sorting algorithm is an important technique through which data is organized in some specific order, which is generally ascending and descending. Different sorting algorithms have different pros and cons because of their efficiency based on time complexity, memory, and ease of implementation.
The Bubble sort algorithm involves comparing and swapping elements until they are arranged in a desired way. Although it is an easy method, it is inefficient when a dataset is huge.
Similar to bubble sort, selection sort involves selecting the smallest elements one after another until they are put in their right place. It involves less swapping than bubble sort but it does not have good time efficiency.
Insertion sort is similar to selection sort as it involves building an ordered array from scratch. In insertion sort, each element is inserted in its proper position. It works fine if the number of elements is small.
Merge sort algorithm applies the approach of divide and conquers to sort the elements efficiently. It divides the array into two parts and sorts them individually and then combines the result.
Similarly, quick sort is an example of divide and conquer algorithm. It picks up a particular element and partitions the array around it.
#CONCLUSION
Every sorting technique has its pros and cons. Basic techniques are helpful for education and small data. Meanwhile, for big data sets, it is necessary to use Merge Sort and Quick Sort. The selection of a sorting technique is dependent on the amount of data.
